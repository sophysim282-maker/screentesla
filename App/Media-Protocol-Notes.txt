ScreenLink native media support implements the AirPlay HTTP/PTTH media exchange
and YouTube's condensed HLS playlist representation, with reference to UxPlay:
https://github.com/FDH2/UxPlay (reference revision 952531ab622f1fd190ca285db0aaca0a788408e4)
Reference files: lib/http_handlers.h, lib/fcup_request.h, lib/airplay_video.c.
UxPlay protocol implementation contributors include fduncanh (2022-2024).
The reference files carry LGPL-2.1-or-later notices. ScreenLink is GPL-3.0.

The browser HLS player is hls.js 1.6.13, MIT licensed. Its full license is
bundled as HLSPlayer-LICENSE.txt. Source: https://github.com/video-dev/hls.js
The build verifies the npm distribution SHA-512 before extracting the player.

No DRM decryption, protected-video bypass, or private iOS background API is
included. The native media implementation requires device testing with YouTube.
